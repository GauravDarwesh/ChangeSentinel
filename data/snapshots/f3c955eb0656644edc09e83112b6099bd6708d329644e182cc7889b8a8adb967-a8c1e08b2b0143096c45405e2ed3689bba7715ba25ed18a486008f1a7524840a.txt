2 Options for submitting
1. Text File. See the File Upload user guide, located within the Reporting Central General User Guide, for the steps on how to create a Text file or look at the steps and examples below.
2. Data Entry Preparing the File Upload for the FXVolume The FXVolume is comprised of both financial and text fields.
Field Values Financial data fields can have either positive, zero, or null values.
Field Labels The identifying label for both financial and text data is the eight-charter MDRM descriptor listed see the table below. Reporting Central uses the MDRM to identify individual report items in the file upload. A full listing of MDRMs can be found in Appendix A below.
Field Character Limits Standard financial data are reported in millions and allows entry of up to 14 digits, with no decimal places.

• Sheet1 contains the report data created from the respondent’s backend system or from a spreadsheet template.
• Sheet2 contains a set of formulae that pulls data from Sheet1 and creates strings for the report header record, rows of data, optional remarks field, end-of-text indicator, and each edit explanation.

5 Sheet 2 Formulae and Strings Report Header Record Excel formula used: Header: =TEXT(Sheet1!B2,"0000000000")&LEFT(TRIM(Sheet1!B3)&" ",10)&TEXT(Sheet1!B4,"mmdd-yyyy")
Text string created by formula: 0000012345FXVOLUME 04-30-2025 Explanation of Excel formula: The formula begins with an equal sign (=) and then combines the respondent ID and series name (FXVOLUME) with the cell reference Sheet1!B4 containing the as-of date to create the string with the header information. The TEXT function appends left-zeroes to the respondent ID in Sheet1!B2 and formats the as-of date in Sheet1!B4. Since the series name is a 10-character field and FXVOLUME occupies only 8 spaces, 2 additional spaces have been added in between the contents of cells B3 and B4 using quotation marks.
FXVOLUME Table A, Line “USD versus EUR, column “Reporting Dealers” Excel formula used: =Sheet1!A5&"+"&Sheet1!B5 Text string created by formula: LFORXT107+1 Explanation of Excel formula: The formula begins with an equal sign (=) and then combines the line number “LFORXT107” (Cell A5) with Cell B5 (USD versus EUR for Reporting Dealers) to create the string of data for the line and column of the report.
The Excel formula connects the contents of the cells together into a string with an ampersand (&). The file uses a plus sign (+) between the line number and the data item of each row.

7 APPENDIX A
File Format and MDRMs for FXVOLUME (Effective 04/30/2025)
Report Header Record for FXVOLUME The Report Header Record must be the first record in the file.
Field Length Type Value/Description Report Institution ID 10 NUM 10-digit respondent identifier Report Name 10 ALPHA ‘FXVOLUME’ followed by two blanks Report As-of date 10 NUM 10-digit date (MM-DD-YYYY) which represents the as-of date of the report
Report Data Record for FXVOLUME There must be one Report Data Record for each data item of the report form.
Field Length Type Value/Description
Line Identifier 9 ALPHA L followed by 8-character Line Identifier of the line of the report form – see next section of this document for Line Identifiers.
The next pair of fields (the separator and the data value) occur once, once for each data column of the report:
+ 1 ALPHA ‘+’ plus, sign, used as field separator Data Value 0-9 NUM Numeric data value being reported for the data cell defined by that row and column. Value must be in on of the following formats: An unsigned 1 to 14-digit value if positive Zero (unsigned) if zero is the applicable value Null, if the data field is not applicable
Note: Do not zero fill the report. If you do not have data for a cell, leave the cell null. The maximum number of digits allowed for the data item is 14.
