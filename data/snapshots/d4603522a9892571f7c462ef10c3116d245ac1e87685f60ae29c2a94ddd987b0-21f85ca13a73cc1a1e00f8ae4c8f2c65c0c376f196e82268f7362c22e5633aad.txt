Overview
This user guide is for FR Y-14 schedules that are processed by the Statistics function:
• FR Y-14 General (GEN) Schedule
• FR Y-14 Annual schedule A, B, C, E, and F
• FR Y-14 Quarterly schedules A.1 through A.10, B, C, D, E, F, G, H.1*, H.2*, H.3*, H.4*, J, K, L, and M
Respondents will submit their XML data files and CSV Respondent Edit Reports for the FR Y- 14A/Q through the Reporting Central application. Respondents will be able to submit any file type for the FR Y-14GEN series (file expectations will be communicated separately). The process of submitting qualitative supporting information will remain unchanged, and respondents should continue to submit that information electronically through OASiS.
The Reporting Central application will subject firm’s XML data files and CSV Respondent Edit Report submissions to basic file level validations that must be resolved before submissions can be accepted. Note that for the FR Y-14GEN series, no file level validations will be performed.
See Appendix A for further information on basic file level validations performed by Reporting Central.

Reporter Dashboard
The Reporter Dashboard appears after the external user logs into Reporting Central and will display as-of dates for all reports the users has access to for the selected RSSD, as well as any as-of dates with a missing report.
Multiple functionalities are displayed on this page that allow the user to:
• Verify the reporting statuses of its reports.
• Select to go to the Search page.
• Select to go to the Data Entry page
• Select the “Open Schedule” icon to go to the Data Entry page for a specific report.
When required to file a future as-of date, the user can navigate to the Data Entry and select from the list of available dates.

Upload for FR Y-14A/Q Series
Note that if a CSV or XML file is larger than 2GB, the file must be compressed.
See Appendix B for further details regarding file compression.
The FR Y-14 Data Entry page has a section to upload Financial Data files and a section for Remarks files.
Upload files may be:
Financial Data
• XML file of financial data
• ZIP file containing one XML file
Remarks
• CSV file of edit remarks
• ZIP file containing one CSV file
The Remarks file must include “RespondentEditReport” within the file name.
You can submit both files at the same time or in separate submissions. Users can also submit multiple files in either section at the same time.
One difference for the FR Y-14 compared to other series is the user is always in edit mode when they enter the screen for a report that has been submitted. For other series the user must select the “Modify” button to enter edit mode.

To begin the uploading process, the user should click on the icon above “Upload Your Attachments Here” in the middle of the page or by dragging the file from their Explorer to the Upload icon.

After selecting a file from their computer, the user can select the Upload button.
The file uploads and appears on the attachment screen. It has not yet been submitted for processing by Reporting Central and the “X” to the right can be used to delete the file.

When a file has a status of “Validating,” the “Refresh” button can be selected periodically to see if the validation is complete. Once validation is complete the status will change to either “Valid” or “Invalid.” In this example, two files have been uploaded for validation in a report with one file that was previously submitted.
The user may select “Save” to leave the page while file validation is in progress. The validation will continue despite the user being on a separate page and the user can return to the Data Entry screen to check the status of the validation process.
9
The “+ Add Row” button can be used to add rows to each section as needed to upload additional files.
When all the files in a report have a status of “Valid,” the user can select the “Submit” button to transmit to the Federal Reserve. Once a file has been submitted it can no longer be deleted or replaced. Any revisions to the report must be made by submitting additional files.

When the user selects to submit they will be asked to confirm the action.
The user receives this confirmation message after submitting the report.
11
The “Close” button will save any changes that have been made and return the user to the Dashboard.
The “Delete” button will give the user the option to delete the draft.

Revisions
For revisions, the user can add files to update their data while any files with a Submitted status cannot be replaced. This can be done by using the “+ Add Row” button that is used to upload multiple files in a section during the original submission.

Validation of XML and CSV files (for all FR Y-14A/Q series) In addition to ensuring a valid file type, Reporting Central checks the uploaded file for other validations listed in Appendix A of this user guide. If an uploaded file fails any validations, Reporting Central will display error messages.
The upload process will capture schema validations and up to 1,000 custom validation errors. If any errors were detected, a link “Click to View Errors” will become available to download the error messages and the status of upload is marked as “Invalid”. If the error count captures more than the allotted amount of errors, you will see a message at the end of the file that says “The maximum number of file validations have been executed.”

Appendix B: File compression for upload files larger than 2GB
A file larger than 2GB must be compressed before it can be uploaded.
Compressed files must be ZIP (legacy compression), not the latest ZIPX extension.. GZ and 7z extensions are also not supported.
The file must also be compressed using the DEFLATE compression algorithm. Please note that the “Windows Send to Compressed Folder” compression method uses a proprietary compression algorithm for files larger than 2GB so a different compression utility such as Winzip or 7-Zip is required for large files (>2GB).
See below for an error message when a ZIP file is uploaded using an unsupported compression algorithm.
22
Using 7-Zip as an example of a supported compression algorithm, the instructions for compressing a file are as followed:
1. Right click on a file to be compressed.
2. Select 7- Zip.
3. Select “Add to archive...”.
23
4. Select “zip” as Archive format.
24
5. Select “Deflate” as Compression method.
6. Click OK button.
Once the file has been compressed into a ZIP file, you can upload to Reporting Central.
