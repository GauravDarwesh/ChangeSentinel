## How the XML File is Structured
Each XML file contains financial data for one reporting entity and as-of date. The data in the file is organized into the following sections.
- ∞ Reporting File
- o Create date
- o Create time
- ∞ Report
- o Respondent Id
- o As Of Date
- o Series Id
- ∞ Item Data
- o Context used for data in a schedule
- o Value
## XML structure or schema:
- &lt;?xml version="1.0" encoding="UTF-8"?&gt;
- &lt;reportingFile xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" createDate="2016-05-20" createTime="09:30:47+05:00" xsi:noNamespaceSchemaLocation="RCInputXML-1.0-20160520.xsd"&gt; &lt;report series="FR2028B" asOfDate="2026-02-02" reporterId="12345"&gt;
- &lt;!-- Cover Page items --&gt;
- &lt;itemData confidential="N" estimated="N" mdrm=" MDRM1111"&gt; &lt;value&gt;value for "MDRM1111" &lt;/value&gt;&lt;/itemData&gt;
- &lt;!-- Schedule items --&gt;
- &lt;itemData confidential="N" estimated="N" mdrm=" MDRM1116"&gt; &lt;value&gt;value for "MDRM1116" &lt;/value&gt;&lt;/itemData&gt;
- &lt;itemData confidential="N" estimated="N" mdrm=" MDRM1117"&gt; &lt;value&gt;value for "MDRM1117"
- &lt;/value&gt;&lt;/itemData&gt;
&lt;/report&gt; &lt;/reportingFile&gt;
Reporting File is a wrapper that encapsulates all the data in the file; it must include the create date and time of the file.
Report is a wrapper that encapsulates all the data items; it must include attributes to identify the respondent Reporter Id, the report As of Date, and the report Series Id.
Item Data is a wrapper that encapsulates the report data values for the reporting entity and as of date.
Important: The upload xml file created can have any name but must have a .xml file extension as the file type.

## Preparing the File Upload for the FR 2028B
The FR 2028B is comprised of both financial and text fields. To minimize issues arising during the creation of the Reporting Central XML file, it is strongly recommended that institutions follow the process described below.
## Field Values
Financial data fields can have either positive, zero, or null values.
## Field Labels
The identifying label for both financial and text data is the eight-charter MDRM descriptor listed see the table below. Reporting Central uses the MDRM to identify individual report items in the file upload.
