3 General Information
The Federal Reserve System’s Reporting Central Application provides the ability for a reporting entity to submit their reports electronically through the use of an XML file. This document describes the required format for creating the XML file for the FR Q-1 (Capital Requirements for Board-Regulated Institutions Significantly Engaged in Insurance Activities) report.
How the XML File Is Structured
Each XML file contains financial data for one reporting entity and as-of date. The data in the file is organized into the following sections.
• Reporting File o Create date o Create time
• Report o Respondent Id Please note that do not include leading zeros if the respondent ID is less than 10 digits.
o As-Of Date o Series Id
• Item Data o Context used for data in a variable schedule o Value
XML structure or schema:
<?xml version="1.0" encoding="UTF-8"?> <reportingFile xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" createDate="1957-08-13" createTime="09:30:47+05:00" xsi:noNamespaceSchemaLocation="RCInputXML-1.0-20160520.xsd"> <report series="FRQ1" asOfDate="2024-12-31" reporterId="12345"> <!-- Cover Page items --> <itemData confidential="N" estimated="N" mdrm=”MDRM1111”> <value>value for “MDRM1111”</value> </itemData>
<!-- Variable schedule items --> <!-- Item #1 --> <itemData confidential="N" estimated="N" mdrm=”MDRM1114”> <value> value for 1st occurrence of “MDRM1114”</value> <context mdrm=”MDRM1010” value=”1”/> </itemData> <itemData confidential="N" estimated="N" mdrm=”MDRM1115”> <value>value for 1st occurrence of “MDRM1115”</value> <context mdrm=”MDRM1010” value=” 1”/> </itemData>
<!-- Item #2 --> <itemData confidential="N" estimated="N" mdrm=”MDRM1114”> <value> value for 2nd occurrence of “MDRM1114”</</value> <context mdrm=”MDRM1010” value=” 2”/> </itemData> <itemData confidential="N" estimated="N" mdrm=”MDRM1115”> <value>value for 2nd occurrence of “MDRM1115”</value> <context mdrm=”MDRM1010” value=” 2”/> </itemData>
<!—Non-Variable schedule items --> <itemData confidential="N" estimated="N" mdrm=”MDRM1116”> <value>value for “MDRM1116”</value> </itemData>
</report> </reportingFile>
4
Reporting File is a wrapper that encapsulates all the data in the file; it must include the create date and time of the file.
Report is a wrapper that encapsulates all the data items; it must include attributes to identity the respondent Reporter Id, the report As of Date, and the report Series Id.
Item Data is a wrapper that encapsulates the report data values for the reporting entity and as of date.
XML Tags and Their Meanings
XML Tag/Attribute Meaning/How Used <reportingFile> A tag used to encapsulate all the data in the file xsi:noNamespaceSchemaLocation="RCInputXML- 1.0-20160520.xsd" Attribute of the reportingFile tag which specifies the location of the Schema createTime=”9:30:47+05:00” Attribute of the reportingFile tag which specifies the time the file was created createDate=”1957-08-13” Attribute of the reportingFile tag which specifies the date the file was created xmlns:xsi="http://www.w3.org/2001/XMLSchemainstance" Optional attribute of the reportingFile tag which tells the schemavalidator that all elements used in the XML file are declared in the "http://www.w3.org/2001/XMLSchema-instance" namespace <report> A tag used to identify the series name, the reporting entity and the as of data of the data.
reporterId=”12345” Attribute of the report tag which specifies the respondent ID.
Please note do not include the leading zeros if the ID is less than 10 digits.
asOfDate=”2024-12-31” Attribute of the report tag which specifies the as of date of the report Series=”FRQ1” Attribute of the report tag which specifies the series name <itemData> A tag used to encapsulate the item and its value from the report confidential="N" or confidential=”Y” This series does allow for confidentiality. The confidential tag for all rows should equal “N” if you choose not to request confidentiality or if you do request confidentiality then all rows should equal “Y”.
estimated="N" This series does not allow for the estimation of date. The estimated tag for all rows should equal “N”. Do not set this to “Y” as this provides no meaningful information to the report submission.
mdrm=”MDRM9999” Attribute of the itemData tag which identifies a specific item in the report <value> A tag encapsulated within itemData tag and contains the value of the item <context> An optional tag encapsulated within itemData tag used to identify the order of a variable list of items mdrm=”MDRM1111” Attribute of the context tag which identifies a group of items in the report value=”1” Attribute of the context tag which identifies the order of in the item group
