Overview
The Federal Reserve System's Structure Central application allows a reporting entity to provide data for the Additional Entities and Foreign Companies sections of the FR Y-7 report as an XML file (among other valid formats). This document describes the required format for creating the XML file for these two sections of the FR Y-7 report.
Additional Entities
The FR Y-7 report’s Additional Entities (AE) section allows the User to download a template file in .XLSX or .XML format and/or upload the User’s AE data file (.PDF, .XLSX, or .XML).
While the system allows the upload of multiple file formats, this document focuses on the XML file format. The template XLSX file (1) can be downloaded within Structure Central (See Appendix A) and should be filled out by the User. Once the User has prepared actual data based on the XLSX file format, the User can upload the actual XLSX file (2) as part of the report submission.

Additional Entities: XML File
Each XML file contains the AE information for a reporting entity and report date.
Below are the tags and attributes used in the XML file followed by sample XML data.
XML Tags and Attributes
Tag Attribute Description <reportingFile> A tag used to encapsulate all the data in the file.
createTime Time the file was created.
createDate Date the file was created.
xmlns:xsi Optional attribute which tells the schema-validator that all items used in the XML file are declared in the "http://www.w3.org/2001/XMLSchema-instance" namespace.
xsi:noNamespac eSchemaLocatio n Optional attribute that indicates the XML Schema document.
<report> A tag used to encapsulate the reporting entity.
series Name of the reporting series. Value is “Y7”.
asOfDate The report date.
<itemGroup> A tag used to encapsulate all the data items within the group.
ref Name of the item group. Value is “addnlEntity" <itemData> A tag used to indicate the data item and its value.
mdrm Identifier for the specific data item in the report.
key Presence of this attributes with a value of “yes” should be included for each <itemGroup> with a unique numeric value.
<value> A tag used to indicate the value of the data item.
Value of zero is indicated by: 0 Value of null is indicated by: <blank>
