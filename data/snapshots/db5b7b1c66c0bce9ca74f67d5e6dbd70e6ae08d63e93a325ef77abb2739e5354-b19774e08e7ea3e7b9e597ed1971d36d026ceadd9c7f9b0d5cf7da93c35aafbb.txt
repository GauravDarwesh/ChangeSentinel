General Information
The Federal Reserve System’s Reporting Central Application provides the ability for a reporting entity to submit their reports electronically using an XML file. This document describes the required format for creating the XML file for the FFIEC030 (Foreign Branch Report of Condition) report. Important Update: for the FFIEC 030S reporting in the XML file as-of 03/31/2026, please see page 11 for further details.
How the XML File Is Structured
Each XML file contains financial data for one reporting entity and as-of date. The data in the file is organized into the following sections.
• Reporting File o Create date o Create time
• Report o Respondent Id o As Of Date o Series Id
• Item Data o Optional context used for data in a variable schedule (such as the FFIEC 030 List of Consolidated Branches) o Value
XML structure or schema:
<?xml version="1.0" encoding="UTF-8"?> <reportingFile xsi:noNamespaceSchemaLocation="RCInputXML-1.0-20160520.xsd" createTime=”09:30:45+05:00” createDate=”2016-08-13” xmlns:xsi="http://www.w3.org/2001/XMLSchemainstance" > <report reporterId=”9999999999” asOfDate=”2016-09-30” series=”SERIESNAME”> <!-- Cover Page items --> <itemData mdrm=”MDRM1111”> <value>value for “MDRM1111”</value> </itemData> <!-- Financial items --> <itemData mdrm=”MDRM1112”> <value>value for ”MDRM1112”</value> </itemData> <itemData mdrm=”MDRM1113”> <value>value for ”MDRM1113”</value> </itemData> <!-- Variable schedule or List of Items --> <!-- Item #1 --> <itemData mdrm=”MDRM1114”> <value> value for 1st occurrence of “MDRM1114”</value> <context mdrm=”MDRM1010” value=”1”/> </itemData> <itemData mdrm=”MDRM1115”> <value>value for 1st occurrence of “MDRM1115”</value> <context mdrm=”MDRM1010” value=”1”/> </itemData>
<!-- Item #2 --> <itemData mdrm=”MDRM1114”> <value> value for 2nd occurrence of “MDRM1114”</</value> <context mdrm=”MDRM1010” value=”2”/>

Reporting File is a wrapper that encapsulates all the data in the file; it must include the create date and time of the file.
Report is a wrapper that encapsulates all the data items; it must include attributes to identity the respondent Reporter Id, the report As of Date, and the report Series Id.
Item Data is a wrapper that encapsulates the report data values for the reporting entity and as of date.

reporterId=”9999999999” Attribute of the report tag which specifies the respondent ID asOfDate=”2016-09-30” Attribute of the report tag which specifies the as of date of the report series=”SERIESID” Attribute of the report tag which specifies the series name <itemData> A tag used to encapsulate the item and its value from the report mdrm=”MDRM9999” Attribute of the itemData tag which identifies a specific item in the report <value> A tag encapsulated within itemData tag and contains the value of the item <context> An optional tag encapsulated within itemData tag used to identify the order of a variable list of items mdrm=”MDRM8888” Attribute of the context tag which identifies a group of items in the report value=”1” Attribute of the context tag which identifies the order of in the item group
