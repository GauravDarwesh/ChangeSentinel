Options for submitting
1. Text File. See the File Upload user guide, located within the Reporting Central General User Guide, for the steps on how to create a Text file.
2. Data Entry Preparing the File Upload for the FR XX-1 The FR XX-1 is comprised of both financial and text fields.
Field Values Financial data fields can have either positive or null values. All dollar amounts are to be reported in thousands of dollars, exclusive of dollar signs and commas.
Field Labels The identifying label for both financial and text data is the eight-charter MDRM descriptor listed see the table below. Reporting Central uses the MDRM to identify individual report items in the file upload.
