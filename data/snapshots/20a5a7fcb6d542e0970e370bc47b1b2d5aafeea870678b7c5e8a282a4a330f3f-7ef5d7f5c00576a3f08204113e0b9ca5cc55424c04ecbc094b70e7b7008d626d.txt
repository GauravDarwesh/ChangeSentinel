Options for submitting
1. Text File. See the File Upload user guide, located within the Reporting Central General User Guide, for the steps on how to create a Text file.
2. Data Entry Preparing the File Upload for the FR 2835a The FR 2835a is comprised of both financial, non-financial and text fields.
Field Values
• Financial data fields can have either positive, zero, or null values. All dollar amounts are to be reported in thousands of dollars, exclusive of dollar signs and commas. This applies to Items 3-6.
• Numeric values (interest rates) are to be reported as a percentage to two decimal places. They can have either positive, zero, or null values. Zero should only be submitted for any items that have a value of zero value. Null values should be submitted for any item that does not apply to the institution. This will only apply to one item, Item 1 “Average nominal finance rate (%), all accounts” (QRCC7164).
• Non-financial data is not a dollar amount and therefore not reported in thousands. This will only apply to Item 2 “Total number of accounts” (QRCC8602) which should be reported as a whole number.
