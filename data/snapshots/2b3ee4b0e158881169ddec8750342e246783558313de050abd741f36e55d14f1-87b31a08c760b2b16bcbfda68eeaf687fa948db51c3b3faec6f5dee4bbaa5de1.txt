## General Information
The Federal Reserve System's Reporting Central Application provides the ability for a reporting entity to submit their reports electronically using an XML file. This document describes the required format for creating the XML file for the FR Y-7Q (Capital and Asset Report for Foreign Banking Organizations) report. A full sample XML file can be found at the end of this document.
## How the XML File Is Structured
Each XML file contains financial data for one reporting entity and as-of date. The data in the file is organized into the following sections.
- Reporting File
- o Create date
- o Create time
- Report
- o Respondent Id
- o As-Of Date
- o Series Id
- Item Data
- o Context used for data in a variable schedule FR Y-7Q schedule Part 2 is variable schedule
- o Value
## XML structure or schema:
```
<?xml version="1.0" encoding="UTF-8"?> <reportingFile xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" createDate="1957-08-13" createTime="09:30:47+05:00" xsi:noNamespaceSchemaLocation="RCInputXML-1.0-20160520.xsd"> <report series="FRY7Q" asOfDate="2026-06-30" reporterId="12345> <!-- Cover Page items --> <itemData confidential="N" estimated="N" mdrm="MDRM1111"> <value>value for "MDRM1111"</value> </itemData> <!-Non-Variable schedule items - Part 1 and Part 1A --> <itemData confidential="N" estimated="N" mdrm="MDRM1116"> <value>value for "MDRM1116"</value> </itemData> <!-- Variable schedule items - Part 2 --> <!-- Item #1 --> <itemData confidential="N" estimated="N" mdrm="MDRM1114"> <value> value for 1 st occurrence of "MDRM1114"</value> <context mdrm="MDRM1010" value="1"/> </itemData> <itemData confidential="N" estimated="N" mdrm="MDRM1115"> <value>value for 1 st occurrence of "MDRM1115"</value> <context mdrm="MDRM1010" value=" 1"/> </itemData> <!-- Item #2 --> <itemData confidential="N" estimated="N" mdrm="MDRM1114"> <value> value for 2 nd occurrence of "MDRM1114"</</value> <context mdrm="MDRM1010" value=" 2"/> </itemData> <itemData confidential="N" estimated="N" mdrm="MDRM1115"> <value>value for 2 nd occurrence of "MDRM1115"</value> <context mdrm="MDRM1010" value=" 2"/> </itemData>
```
&lt;/report&gt; &lt;/reportingFile&gt;
Reporting File is a wrapper that encapsulates all the data in the file; it must include the create date and time of the file.
Report is a wrapper that encapsulates all the data items; it must include attributes to identity the respondent Reporter Id, the report As of Date, and the report Series Id.
Item Data is a wrapper that encapsulates the report data values for the reporting entity and as of date.
XML Tags and Their Meanings
| XML Tag/Attribute | Meaning/How Used |
| --- | --- |
| <reportingFile> | A tag used to encapsulate all the data in the file |
| xsi:noNamespaceSchemaLocation="RCInputXML- 1.0-20160520.xsd" | Attribute of the reportingFile tag which specifies the location of the Schema |
| createTime="09:30:45" | Attribute of the reportingFile tag which specifies the time the file was created |
| createDate="2016-08-13 | Attribute of the reportingFile tag which specifies the date the file was created |
| xmlns:xsi="http://www.w3.org/2001/XMLSchema- instance" | Optional attribute of the reportingFile tag which tells the schema-validator that all elements used in the XML file are declared in the "http://www.w3.org/2001/XMLSchema- instance" namespace |
| <report> | A tag used to identify the series name, the reporting entity and the as of data of the data. |
| reporterId="9999999999" | Attribute of the report tag which specifies the respondent ID |
| asOfDate="2016-09-30" | Attribute of the report tag which specifies the as of date of the report |
| series="SERIESID" | Attribute of the report tag which specifies the series name |
| <itemData> | A tag used to encapsulate the item and its value from the report |
| mdrm="MDRM9999" | Attribute of the itemData tag which identifies a specific item in the report |
| <value> | A tag encapsulated within itemData tag and contains the value of the item |
| <context> | An optional tag encapsulated within itemData tag used to identify the order of a variable list of items |
| mdrm="MDRM8888" | Attribute of the context tag which identifies a group of items in the report |
| value="1" | Attribute of the context tag which identifies the order of in the item group |

## Example FR Y-7Q XML File Upload
The following FR Y-7Q XML file upload example includes sample items for the cover page, Part 1A, Part 1B, and Part 2 Schedule.
```
<?xml version="1.0" encoding="UTF-8"?> <reportingFile xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" createDate="1957-08-13" createTime="09:30:47+05:00" xsi:noNamespaceSchemaLocation="RCInputXML-1.0-20160520.xsd"> <report series="FRY7Q" asOfDate="2026-06-30" reporterId="12345"> <!-- Cover Page items --> <itemData confidential="N" estimated="N" mdrm="FBOQC490"> <value>John Smith</value> </itemData> <itemData confidential="N" estimated="N" mdrm="FBOQ8901"> <value>Officer</value> </itemData> <!-Part 1A Schedule items --> <itemData confidential="N" estimated="N" mdrm=" FBOQB162"> <value>0</value> </itemData> <itemData confidential="N" estimated="N" mdrm="FBOQ8274"> <value>200</value> </itemData> <!-Part 1B Schedule items --> <itemData confidential="N" estimated="N" mdrm=" FBOQP859"> <value>1000</value> </itemData> <itemData confidential="N" estimated="N" mdrm="FBOQP865"> <value>2000</value> </itemData> <!-- Part 2 items --> <!-- Item #1 --> <itemData confidential="N" estimated="N" mdrm="FBOQ9017"> <value>Title 1</value> <context mdrm="FBOQN186" value="1"/> </itemData> <itemData confidential="N" estimated="N" mdrm="FBOQ9005"> <value>USA</value> <context mdrm="FBOQN186" value="1"/> </itemData> <!-- Item #2 --> <itemData confidential="N" estimated="N" mdrm="FBOQ9017"> <value>Title 2</value> <context mdrm="FBOQN186" value="2"/> </itemData> <itemData confidential="N" estimated="N" mdrm="FBOQ9005"> <value>USA</value> <context mdrm="FBOQN186" value="2"/> </itemData> </report> </reportingFile>
```
## Report Submission in Reporting Central Cloud
In Reporting Central, select the "Upload file" tab and then click the "Upload your files here" tab.
<!-- image -->
Then, navigate to the stored text file and select the filename so it appears in the 'File name:' box. Select "Open" to continue.
<!-- image -->
Next select the "Upload" tab.
<!-- image -->
If there are no formatting issues during the file upload you will get a "File Upload Complete" message the data will load directly into the report screen.
<!-- image -->
The report data can then be validated, saved, submitted or deleted. If errors exist in the text file error messages will appear in the file upload window, which can be used to troubleshoot any formatting issues.
