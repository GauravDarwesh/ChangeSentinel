2. Data Entry Preparing the File Upload for the FR 2835 The FR 2835 is comprised of both financial and text fields.
Field Values Financial data fields can have either positive, zero, or null values.
All numeric values (interest rates) are to be reported as a percentage to two decimal places.
Zero should only be submitted for any items that have a value of zero value. Null values should be submitted for any item that does not apply to the institution.
Field Labels The identifying label for both numeric and text data is the eight-charter MDRM descriptor listed see the table below. Reporting Central uses the MDRM to identify individual report items in the file upload.
