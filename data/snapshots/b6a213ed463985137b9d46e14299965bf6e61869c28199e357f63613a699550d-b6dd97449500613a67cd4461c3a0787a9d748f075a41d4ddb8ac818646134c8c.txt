Overview
The Federal Reserve System’s Structure Central application allows a reporting entity to provide data for the Additional Entities and Foreign Companies sections of the FR Y-7 report as an XLSX file (among other valid formats).
This document describes the required format for creating the XLSX file for these two sections of the FR Y-7 report.
Additional Entities
The FR Y-7 report’s Additional Entities (AE) section allows the User to download a template file in .XLSX or .XML format and/or upload the User’s AE data file ( .PDF, .XLSX, or .XML).
While the system allows the upload of multiple file formats, this document focuses on the XLSX file format. The template XLSX file (1) can be downloaded within Structure Central (see Appendix A) and should be filled out by the U ser. Once the User has prepared actual data based on the XLSX file format, the User can upload the actual XLSX file (2) as part of the report submission.
3
Foreign Companies
The FR Y-7 report’s Foreign Companies (FC) section allows the User to download a template file in .XLSX or .XML format and/or upload the User’s FC data file (.PDF, .XLSX, or .XML).
While the system allows the upload of multiple file formats, this document focuses on the XLSX file format. The template XLSX file (1) can be downloaded within Structure Central (see Appendix B) and should be filled out by the U ser. Once the User has prepared actual data based on the XLSX file format, the User can upload the actual XLSX file (2) as part of the report submission.
