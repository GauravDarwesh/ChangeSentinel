How to create a FR2004 Text file from a spreadsheet Step 1. Create a spreadsheet with a layout like report form, for example the FR 2004A, along with its corresponding cell identifiers and its data values from each item on the FR 2004A report form. You should skip those rows on the form that doesn’t contain cells to be filled-in.
A sample picture of a portion of the FR 2004A report is displayed below: Ste p 2. Once the entire report form is populated on a spreadsheet and the data values have been entered, it is time to format all your entries from the first Cell Identifier and Value up to and including the last Cell Identifier and Value into a Reporting Central required format.
To accomplish this the following technique may be used
- select cells starting with first Cell Identifier and Value (starting with the first Cell Identifier row/column) up to the l ast Cell Identifier and Value (ending with the last Value row/column).
- pas te selection to another spreadsheet and save it in *.txt file: On the spreadsheet file: do a File > Save As, select Text (Tab delimited) in the Save as type section. Type a name for the file and click the Save button. Then click OK and Yes to the two MS Excel prompts.
- If you open the text file, you should see something like this: -
- use “Replace All” for the following: “<tab>” to “+” and after that “+L” to “L” to see something like that:
Step 3. The last step is adding the respondent ID, as-of-date and the report form name. Open the newly created text file, place the cursor before the Cell Identifier on the beginning of the first row of data and press the return key to create an empty first row. Then type in your 10-digit respondent ID code immediately followed by FR2004A and three blank spaces (Remember the report form name must be 10 characters long) and then the report’s as-ofdate (in the format of the date on the first line below.) Save the file and you’re done. Once you’re done, your first row of data should look similar in format to the file below.
N ow you can go ahead and submit this text file to Reporting Central.
File Format for FR2004A “Weekly Report of Dealer Positions” (Effective 01/05/2022) Report Header Record for FR2004A The Report Header Record must be the first record in the file.
Field Length Type Value/Description Report Institution ID 10 Numeric 10-digit respondent identifier Report Name 10 Alpha ‘FR2004A' followed by three blanks Report As-of-date 10 Numeric 10-digit date (MM-DD-YYYY) which represents the as-of date of the report.
Report Data Record for FR2004A There must be one Report Data Record for each line of the report form.
Field Length Type Value/Description Cell Identifier 9 Alpha L followed by 8-character Cell Identifier of the line of the report form: "MDRM" ID for the FR2004A from (4-char): GSWA and the first field of the corresponding line "MDRM" (4-char) (M438-M497). See the list below for the MDRM for each cell The nex t pair of fields is the separator and the data value. In case of the FR2004A report, there are only two columns per Line, so two cell identifiers are followed by their values separated by field separators.
Field Length Type Value/Description + 1 Alpha '+' plus sign, used as field separator Data Value 0-9 Numeric Numeric data value being reported for the data cell defined by that row and column. Value must be in one of the following formats:
1. An unsigned one to nine-digit value if positive
2. Zero (unsigned) if zero is the applicable value
3. Null, if the data field is not applicable.
Note: Do not zero fill the report. If you do not have data for a cell, please leave the cell null.
