## Overview
The Federal Reserve System's Structure Central application allows a reporting entity to provide data for the Securities Holders and Insiders sections of the Annual Report of Holding Companies - FR Y-6 (FR Y-6) as an XML file (among other valid formats).
This document describes the required format for creating the XML file for these two sections of the FR Y-6 report.
## Securities Holders
The FR Y-6 report's Securities Holders (SH) section allows the User to indicate if there were changes to Item 3 SH from the prior year, download a sample file in .XLSX or .XML format and/or upload the reporter's SH data file (.PDF, .XLSX, or .XML).
While the system allows the upload of multiple file formats, this document focuses on the XML file format. The sample XML file (1) should be used by the Reporter as a guide for the contents of the XML file to be uploaded. Once the reporter has prepared actual data based on the XML file format, the Reporter can upload the actual XML file (2).

## Securities Holders: XML File
Each XML file contains the Securities Holders information for a reporting entity and report date. The field type and max length specification should follow the table above for each data value.
Below are the tags and attributes used in the XML file followed by sample XML data.
## XML Tags and Attributes
| Tag | Attribute | Description |
| --- | --- | --- |
| <reportingFile> | | A tag used to encapsulate all the data in the file. |
| | createTime | Time the file was created. |
| | createDate | Date the file was created. |
| | xmlns:xsi | Optional attribute which tells the schema-validator that all items used in the XML file are declared in the "http://www.w3.org/2001/XMLSchema-instance" namespace. |
| | xsi:noNamespac eSchemaLocatio n | Optional attribute that indicates the XML Schema document. |
| <report> | | A tag used to encapsulate the reporting entity. |
| | series | Name of the reporting series. Value is "Y6". |
| | asOfDate | The report date. |
| <reportingEntity> | | A tag used to encapsulate the item groups. |
| | mdrm | Identifier for the legalName reporting entity field. |
| | legalName | Legal Name of the reporting entity. |
| <itemGroup> | | A tag used to encapsulate all the data items within the group. |
| | ref | Name of the item group. Value is "SecHolderAsOf" or "SecHolderDuring". |
| <itemData> | | A tag used to indicate the data item and its value. |
| | mdrm | Identifier for the specific data item in the report. |
| | key | Presence of this attributes with a value of "yes" should be included for each <itemGroup> with a unique numeric value. |
| <value> | | A tag used to indicate the value of the data item. Value of zero is indicated by: 0 Value of null is indicated by: <blank> |
